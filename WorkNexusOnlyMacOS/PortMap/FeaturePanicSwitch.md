# FeaturePanicSwitch (lib/features/panic_switch → Sources/FeaturePanicSwitch)

"Thầy vô" (boss alert): a floating button above every app sends the "Thầy vô" sticker to the team group on a triple click; every WorkNexus (Flutter or native) that receives it brings the chosen app forward and hides the chosen apps and itself. Offered only to users signed in to `https://zentao.oasoft.xyz:4433/zentao`; the team group is found by name ("VN Mobile Tester", letters and digits only). Ported up to upstream `a1def8d7` (one test chat for sending and listening).

Public entry: `PanicSwitchFeature.makeModel(settingsFile:sticker:chats:accounts:)` → `PanicSwitchModel` (`start()`, `stop()`, `edit(_:)`, `tryNow()`, `watchChats(selfTitle:)`, `loadMembers()`, `loadApps()`), `PanicSwitchSettingsCard(model:)`. Chat is reached only through the module's own `PanicChatGateway` (features never import each other): `App/Sources/PanicSwitchWiring.swift` (`ChatPanicGateway`) adapts `FeatureChat.ChatRepository` to it, and `CompositionRoot` starts the model with the app (not in demo mode). The card sits on Settings → General after the mini apps card (Flutter: the workspace Settings page, after the mini apps card).

**Interop with the Flutter app.** Both send the sticker the same way: `sendFile(name: "worknexus-thayvo-v1.png", bytes: thay_vo.png, mimeType: "image/png")` → the chat server stores the upload and the message goes out as content type `image` with content `{"name":"worknexus-thayvo-v1.png","size":…,"send":true,"type":"image/png","id":…,"time":…,"width":…,"height":…}` (`ChatAttachmentLoader.upload`, same as chat_attachment_loader.dart). The bytes are `App/Resources/Stickers/WorkNexus/thay_vo.png`, the very file of the Flutter `assets/stickers/WorkNexus/thay_vo.png` (`Scripts/sync-assets.sh`). Both recognise it the same way: an image message whose file name, lowercased, is `worknexus-thayvo-v1.png` (the server gives each upload a new id, so the name is the identity), sent no more than 30 s before or after now, in the chat listened in, not by you. Settings are the same JSON object as the Flutter app's `panic_switch.config` value (incl. the two legacy shapes), kept in `<Application Support>/panic_switch.json`.

macOS only: the Windows layered window / foreground workaround and the Linux GTK window, wmctrl/xdotool/gtk-launch switcher and the Wayland note are not ported (`AppSwitcher.canRaiseApps` dropped). Adapted: the triple click is counted by a value object (`TripleClickCounter`, 0.5 s between clicks) instead of AppKit's `clickCount == 3`; the app pickers show each app's icon; the incoming listener checks the reserved file name off the main thread before anything else; the chats are watched only while the settings card is on screen, or until the team group is found.
